# 🎬 StreamX — Movie Streaming Landing Page

A responsive movie streaming landing page built with React + Vite, powered by the TMDB API.

## 🚀 Tech Stack

- React 19
- Vite
- Framer Motion
- Lucide React
- TMDB API

## ✨ Features

- Hero banner with featured movie
- Trending movies grid
- Genre category filter
- Live search with debounce
- Movie detail modal
- Skeleton loading state
- Hover animations
- Fully responsive

## 📦 Installation

git clone https://github.com/garvitajain23/RFT-Frontend-Internship/tree/main/Day-24.git
cd movie-streaming
npm install

## ⚙️ Configuration

Open src/App.jsx and replace the API key:

const API_KEY = "your_tmdb_api_key_here";

Get a free key at:
https://www.themoviedb.org/settings/api

## ▶️ Run Locally

npm run dev
