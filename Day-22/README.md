# 📊 Metrik — Responsive Analytics Dashboard

A modern, fully responsive Analytics Dashboard built with **React.js** and **Recharts** as part of a Frontend Development Internship project at RFT.

---

## 🚀 Live Demo

> Run locally using the steps below.

---

## ✨ Features

- 📱 **Fully Responsive** — works on mobile, tablet, and desktop
- 🌙 **Dark / Light Mode** toggle
- 🔍 **Search Functionality** — filters the top pages table in real time
- 📊 **Interactive Charts** — Line chart and Bar chart using Recharts
- 🃏 **Statistics Cards** — with trend indicators
- 💀 **Loading Skeleton** — shimmer animation on initial load
- 🗂️ **Sidebar Navigation** — collapsible on mobile
- ⚡ **Smooth Animations** — hover effects and transitions throughout

## ⚙️ Getting Started

### Prerequisites

- Node.js v18+
- npm

### Installation

    # Clone the repository
   

    # Navigate into the project
    cd analytics-dashboard

    # Install dependencies
    npm install

### Run Locally

    npm start

Open http://localhost:3000 in your browser.
